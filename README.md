# 📚 Book Library Tracker

A simple and responsive **Book Library Tracker** web application built using HTML, CSS, and JavaScript.

The application allows users to manage their personal book library by adding books, updating their reading status, giving ratings, searching, sorting, and viewing simple library statistics.
